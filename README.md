# Agents in Parallel

*Patterns and proof for orchestrating many AI agents.*

📖 **Read online:** https://nazt.github.io/agents-in-parallel/

The value of many agents is not speed. It is three things: **diversity of method**
(parallel agents with different angles see what one cannot), **adversarial
verification** (refute findings; gate irreversible actions), and **idempotent
declare-then-reconcile** (the team is a file; every operation is a re-runnable move
toward it). Each chapter pairs a pattern with a concrete proof.
